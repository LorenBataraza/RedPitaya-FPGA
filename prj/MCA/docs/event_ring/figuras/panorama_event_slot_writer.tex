% Panorama de EVENT_SLOT_WRITER: la última etapa del event_ring. Toma un evento
% completo de la stage y lo serializa en un slot de 2^(slot_shift-3) palabras de
% 64 b: cabecera, muestras empaquetadas, relleno y footer. Un mux elegido por el
% estado de la FSM arma cada palabra; la salida se sostiene hasta que el

% cruza son sus puertos, sólo con el nombre.

% los docs que la incluyen.

%
