% Las fuentes de eventos. Arriba, la interfaz EventSource (no es una clase: es
% el contrato que documenta sources.py y que se cumple por duck typing) y
% quién llama cada parte: AcquisitionSession el ciclo de vida, ReaderThread el
% lazo caliente. Al medio, las dos implementaciones sobre la placa. Abajo, de
% dónde lee cada una: BramSource por librp sobre la BRAM del scope, RingSource por mmap del
% ring en DDR; las dos reciben el scope (un MultiTriggerScope) sólo para armar
% el trigger. FakeSource, el sustituto sin placa, no se dibuja: está en
% docs/API/diseno_de_clases.md §9.1.
% Fuentes: software/API/osciloscope_store/sources.py (interfaz, BramSource,
% FakeSource), software/API/osciloscope_ring.py (RingSource),
% software/API/osciloscope_store/reader.py (_loop), session.py (__init__,
% start, stop). El texto que acompaña está en
% docs/API/diseno_de_clases.md §6. Estilo: docs/figuras/estilo_tikz.tex y
% clases_estilo.tex.
%
% Compilar:   pdflatex clases_fuentes.tex
%             pdftocairo -svg clases_fuentes.pdf clases_fuentes.svg
%
