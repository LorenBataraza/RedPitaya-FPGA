% Una corrida del osciloscopio, en tres subfiguras horizontales.
% (a) El lazo del hilo lector (osc-reader), el mismo con las dos fuentes: arm()
%     una vez, read_batch() una vez por lote, close() una vez. Es lo que la API
%     abstrae: el lector no sabe por qué camino llegan los datos.
% (b) Lo que hace read_batch con el ring (osciloscope_ring_leer_lote): un bloque
%     de slots por vuelta, con los créditos y los descartes que cuenta la PL.
%     Nadie re-arma desde el PS. Sin lote no consume: los eventos esperan en la
%     DDR.
% (c) Lo que hace read_batch con la BRAM (osciloscope_leer_lote): un evento por
%     vuelta: esperar, anotar, leer, re-armar, anotar el tiempo muerto. Sin lote,
%     el evento se cuenta como descartado y se re-arma sin leer.
% El MCA va aparte, en corrida_mca.tex.
% Notación de máquina de estados: el punto lleno es la entrada a read_batch, el
% punto con anillo es la vuelta a Python.
% Fuentes: software/API/osciloscope_store/{reader.py (_loop_lotes), sources.py,
% session.py}, software/libmca/src/{osciloscope_lote.c,osciloscope_ring.c}. El
% texto que acompaña está en docs/API/adquisicion_de_eventos.md §2; el epígrafe,
% en maquinas_estados.txt. Estilo: docs/figuras/estilo_tikz.tex.
%
% Compilar:   pdflatex maquinas_estados.tex
%             pdftocairo -svg maquinas_estados.pdf maquinas_estados.svg
%
