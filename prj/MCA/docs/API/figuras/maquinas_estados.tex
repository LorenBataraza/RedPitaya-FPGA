% Las dos secuencias que ve el usuario, como dos subfiguras separadas para
% citarlas como (a) y (b). (a), el lazo de EventSource: arm() una sola vez, y
% después una vuelta por evento que termina siempre en rearm(), también cuando
% el lector descarta. Entre que wait_event() devuelve y rearm() termina, el
% scope no dispara: ese es el tiempo muerto. (b), el flujo del MCA, que es
% lineal porque el hardware acumula solo.

%
