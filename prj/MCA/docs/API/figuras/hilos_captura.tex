% Los hilos de la captura del osciloscopio en el tiempo: una corrida de
% AcquisitionSession con BramSource, de start() a stop(). Una línea de vida por
% hilo (principal, osc-reader, osc-writer), más la PL y el disco. Sobre cada
% hilo, el color dice qué corre y si tiene el GIL: Python (con el GIL), C de
% libmca (sin el GIL: ctypes lo suelta) o el write() del escritor (sin el GIL).
% Lo que muestra: el lector pasa casi todo el tiempo en C y vuelve a Python una
% vez por lote, así que el escritor, que también pasa su tiempo largo sin el GIL,
% no lo frena; y los dos se pasan los batches por las colas mientras el otro
% sigue trabajando.
% No está a escala. Con RingSource el tramo de C es osciloscope_ring_leer_lote
% y los mensajes a la PL son los del ring (docs/event_ring/figuras/secuencia/);
% el resto no cambia. Lo que hace C por evento está en maquinas_estados; los
% batches, en pool_batches.
% Fuentes: software/API/osciloscope_store/{session.py,reader.py,storage.py},
% software/API/osciloscope_store/sources.py (BramSource), software/API/osciloscope.py
% (Lector). El texto que acompaña está en docs/API/adquisicion_de_eventos.md §3;
% el epígrafe, en hilos_captura.txt. Estilo: docs/figuras/estilo_tikz.tex.
%
% Compilar:   pdflatex hilos_captura.tex
%             pdftocairo -svg hilos_captura.pdf hilos_captura.svg
%
