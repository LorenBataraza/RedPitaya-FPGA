% La capa de C del MCA: libmca, los niveles 1 a 4 en una biblioteca con la
% forma de rp-api. Tres columnas:
%   izquierda  quién la llama: el binding de Python (por ctypes, figura
%              clases_mca) y los programas en C;
%   centro     mca_h, el handle opaco, con todas las operaciones como funciones
%              que devuelven un código y entregan el resultado por puntero; y
%              debajo el bus, mca_bus, con el backend devmem, que hereda a la
%              manera de C (la base como primer miembro);
%   derecha    los tipos de valor que cruzan la interfaz y, abajo, la PL.
% El backend por callbacks (bus_callback.c) no se dibuja: sirve a los
% sustitutos de prueba (diseno_de_clases.md §9.1).
% Fuentes: software/libmca/include/{mca.h,mca_regs.h,mca_bus.h},
% software/libmca/src/{mca.c,bus.h,bus.c,devmem.h,bus_devmem.c,bus_mmap.c}.
% El texto que acompaña está en docs/API/diseno_de_clases.md §3. Estilo:
% docs/figuras/estilo_tikz.tex y clases_estilo.tex.
%
% Compilar:   pdflatex clases_libmca.tex
%             pdftocairo -svg clases_libmca.pdf clases_libmca.svg
%
