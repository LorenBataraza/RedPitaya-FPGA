% Los bloques de libmca: un handle por bloque de la PL, con sus operaciones
% agrupadas. Lo que todos comparten (el ciclo de vida, el acceso crudo, la tabla
% de registros, mca_bloque, el bus) está una sola vez, en clases_bloque; los dos
% lazos por lote y sus structs, en clases_lotes. Acá va lo que distingue a cada
% bloque.
%   arriba   multitrigger_h (slot 3), mca_h (slot 7) e integration_h (slot 6):
%            los bloques sólo de registros;
%   abajo    osciloscope_h (slot 1), osciloscope_ring_h (slot 2, el único con una
%            región de DDR) y gen_pulsos_h (slot 2, 0x4021_0000, con un segundo
%            bus para el lazo digital de HK); debajo, gen_disparos, el motor de
%            disparos que comparten los dos generadores, sin hardware.
% Fuentes: software/libmca/include/{mca.h,mca_regs.h,integration.h,multitrigger.h,
% osciloscope.h,osciloscope_lote.h,osciloscope_ring.h,gen_pulsos.h,gen_disparos.h}.
% El texto que acompaña está en docs/API/libmca.md §3; el epígrafe, en
% clases_libmca.txt. Estilo: docs/figuras/estilo_tikz.tex y clases_estilo.tex.
%
% Compilar:   pdflatex clases_libmca.tex
%             pdftocairo -svg clases_libmca.pdf clases_libmca.svg
%
