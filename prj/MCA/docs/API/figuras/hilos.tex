% Los tres sistemas de concurrencia del software, uno por banda: el pipeline de
% adquisición (colas), el servidor (un lock) y la GUI (señales de Qt). Cada uno
% elige su primitiva y no comparte hilos con los otros; el servidor y la GUI
% sólo se hablan por el socket. A la izquierda de cada banda, el recurso que se
% protege; a la derecha, lo que sale de la máquina (disco o red).
% El detalle del pipeline (el lazo de C sin el GIL, el pool y las colas en el
% tiempo) está en hilos_captura y pool_batches.
% Fuentes: software/API/osciloscope_store/{session,reader,storage,annotators}.py,
% software/app/mca_server.py, software/app/mcamon.py. El texto que acompaña está
% en docs/API/arquitectura_software.md §2; el epígrafe, en hilos.txt. Estilo:
% docs/figuras/estilo_tikz.tex.
%
% Compilar:   pdflatex hilos.tex
%             pdftocairo -svg hilos.pdf hilos.svg
%

  parte/.style    = {anchor=north west, font=\small\bfseries, inner sep=0pt},
  donde/.style    = {anchor=north east, font=\scriptsize\itshape, black!70, inner sep=0pt},
}
