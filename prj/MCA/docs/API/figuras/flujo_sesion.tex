% El flujo de una sesión de captura (AcquisitionSession), de start() a stop(), sin el
% detalle de lo que pasa adentro del lector y del escritor: el lector llena un batch
% desde la fuente y el escritor lo guarda, y se lo pasan por las colas. Es la versión
% para el cuerpo del texto; el detalle (las llamadas de C, el GIL en cada tramo, los
% mensajes a la PL por evento, el .tmp y el os.replace) está en hilos_captura, que
% puede ir en un apéndice.
% Los pasos son los de session.py: start() baja el intervalo de cambio del GIL a 1 ms,
% arranca los anotadores, arma la fuente y lanza el escritor y el lector; wait() mira
% cada 0.2 s; stop() vacía el ring (con RingSource, hasta 5 s), para el lector (el
% parcial y el centinela), espera al escritor, para los anotadores, cierra la fuente,
% restaura el intervalo y escribe run_summary.json.
% Fuentes: software/API/osciloscope_store/{session.py,reader.py,storage.py}.
% El epígrafe, en flujo_sesion.txt. Estilo: docs/figuras/estilo_tikz.tex.
%
% Compilar:   pdflatex flujo_sesion.tex
%             pdftocairo -svg flujo_sesion.pdf flujo_sesion.svg
%
