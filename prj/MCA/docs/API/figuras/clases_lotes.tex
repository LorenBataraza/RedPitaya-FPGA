% Los dos lazos por lote de libmca: donde la biblioteca se encuentra con la
% adquisición de eventos. Una columna por lazo, con lo mismo en cada fila:
%   arriba     el envoltorio de Python que lo llama (Lector, LectorRing), dueño
%              de los structs;
%   al medio   la función de C, con los handles que recibe a un costado;
%   abajo      lo que recibe: la configuración, el estado que sigue de una
%              llamada a la otra, y las columnas del lote, que son punteros a los
%              arreglos del EventBatch desde batch.n.
% Al centro, lo que los dos lazos comparten: el resultado (n, descartados,
% asignados), la calibración de librp y el EventBatch donde escriben.
% Lo que hace cada lazo por evento o por bloque está en maquinas_estados.
% Fuentes: software/libmca/include/{osciloscope_lote.h,osciloscope_ring.h},
% software/API/osciloscope.py (Lector), software/API/osciloscope_ring.py
% (LectorRing), software/API/osciloscope_store/events.py (EventBatch).
% El texto que acompaña está en docs/API/libmca.md §4; el epígrafe, en
% clases_lotes.txt. Estilo: docs/figuras/estilo_tikz.tex y clases_estilo.tex.
%
% Compilar:   pdflatex clases_lotes.tex
%             pdftocairo -svg clases_lotes.pdf clases_lotes.svg
%
