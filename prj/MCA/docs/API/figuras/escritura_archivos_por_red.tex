% La escritura de archivos por red (ring.iniciar(destino='red')): la placa no tiene
% sesión; un hilo del servidor (ring-tx) corre el lazo de C osciloscope_ring_enviar,
% que manda los slots crudos por un socket. En la PC, ring-rx los guarda tal cual en
% ring_*.bin y convertir los pasa a los mismos chunk_*.npz con el pool y el
% ChunkWriter de la sesión.
% Borde grueso: lo que se agregó para la salida por red. RingSource sigue: configura el ring y el
% estímulo, pero no lee.
% Columnas: las máquinas (PL, DDR, PS de la placa, PC), como en niveles.tex; colores
% de bloque: azul hilo de Python, rojo lazo de C, como en niveles y hilos.
% Fuentes: software/API/osciloscope_ring.py (EmisionRing, RingSource),
% software/API/ring_red.py (RecepcionRing, convertir),
% software/libmca/include/osciloscope_ring.h (osciloscope_ring_enviar),
% software/app/mca_server.py (ring.iniciar). El texto que acompaña está en
% docs/event_ring/salida_por_red.md; el epígrafe, en escritura_archivos_por_red.txt.
% Estilo: docs/figuras/estilo_tikz.tex.
%
% Compilar:   pdflatex escritura_archivos_por_red.tex
%             pdftocairo -svg escritura_archivos_por_red.pdf escritura_archivos_por_red.svg
%
