% Panorama de la primera versión del MCA (MCA1), la de antes de las ranuras y
% del banco de trapecios, en el mismo estilo que panorama_mca_top.tex para que
% se puedan comparar. Es el estado del RTL en el commit 126f0f3 («Refactor
% MCA»), el último con MAGIC = "MCA1": una sola ventana, abierta por el Schmitt
% propio o por trig_i, cerrada por histéresis o por compuerta fija, y una cola
% de publicación de PUB_K lugares. La versión de antes del refactor tenía sólo
% el Schmitt y la publicación bloqueante.
% Fuente: git show 126f0f3:prj/MCA/modulos/mca/rtl/{mca_top,mca_window,mca_publish}.sv
%
% Igual que en el panorama del top, la entrada (mux de canal y decimación) y el
% banco de registros no se dibujan. El color es la función:
%   azul      línea de base
%   amarillo  segmentación: quién abre y quién cierra la ventana
%   verde     estadísticos del pulso: los acumuladores y los divisores
%   naranja   publicación: de la ventana cerrada al histograma
%   gris      contabilidad
% El epígrafe no va en la figura: está en panorama_mca1.txt.
%
% Compilar:   pdflatex panorama_mca1.tex
%             pdftocairo -svg panorama_mca1.pdf panorama_mca1.svg
%
