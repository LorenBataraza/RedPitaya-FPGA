%
% EL COLOR ES LA FUNCIÓN, como en panorama_mt.tex: amarillo selección,
% naranja escudo, gris registros. Las operaciones van con su símbolo.
% El epígrafe no va en la figura: está en panorama_mt_event_logic.txt y en el
% doc que la incluye.
%
% Compilar:   pdflatex panorama_mt_event_logic.tex
%             pdftocairo -svg panorama_mt_event_logic.pdf panorama_mt_event_logic.svg
%
